Scaling up lensing detection with machine learning

Jul 2025 · Code · Paper

Finding strongly lensed gravitational-wave events matters for science, and it is expensive. Classical Bayesian methods need a full pairwise parameter estimation for every pair of detected signals. As detector catalogs grow, that means millions of pairs, which is not feasible.

The pipeline

  • Turn each signal into a Q-transform spectrogram (a time-frequency image).
  • Generate rapid Bayestar sky maps to localize each event.
  • Extract features from both with a CNN (DenseNet).
  • Combine the outputs with XGBoost classifiers to rank pairs as lensing candidates.

The hybrid model screens millions of candidate pairs in seconds, with accuracy close to the full Bayesian analysis: about 1000x lower latency across 5,000+ events.

Results and impact

The pipeline was validated on simulated binary black hole signals in Gaussian noise. It saves orders of magnitude of computation, which makes lensing searches practical for next-generation detectors such as LISA and the Einstein Telescope. A later version became part of LensingFlow, an automated workflow for gravitational-wave lensing analyses (paper).
